# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the code and the ideas, not the people. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

To report unacceptable behaviour, contact the maintainer, [@ChrisAbner](https://github.com/ChrisAbner), privately through GitHub. Reports are handled confidentially.
